# trpg-scenario-bgm

TRPGシナリオの頒布用ルームZIP（ココフォリア）から参照するBGMの置き場です。置いているのは再配布が許された曲だけです。
ファイル名やこのリポジトリの名前を変えると、頒布済みのルームZIPでBGMが鳴らなくなります。
